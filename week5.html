사용자 API

현재 사용자 조회, 회원가입, 프로필, 알림 설정, 기기 토큰과 관련된 API를 정리함

/사용자 0. 정보 가져오기 - GET /users/me - Firebase 인증 토큰 확인 - auth_uid 기준 현재 사용자 조회 - user_id, friend_code, email, name, experience_start_date - profile_title_code, profile_theme_code, profile_image 1. 회원가입 - POST /users - Firebase 인증 확인 - auth_uid로 기존 회원 확인 - 신규 사용자면 users 생성 - 기본 user_settings 생성 2. 로그인 - GET /users/me - Firebase 인증 사용자 확인 - auth_uid 기준 기존 회원 여부 확인 - POST /users/me/device-tokens - 현재 기기의 FCM 토큰 등록 또는 갱신 3. 프로필 수정 - PATCH /users/me/profile - name - profile_image - experience_start_date 4. 프로필 꾸미기 - PATCH /users/me/profile-custom 5. 알림 설정 - PATCH /users/me/user_settings - 깨우기 알림 - 친구 신청 알림 - 친구 수락 알림 - 조회 GET /users/me 6. 탈퇴하기 - DELETE /users/me 7. 로그아웃 - DELETE /users/me/device-tokens - 현재 기기의 FCM 토큰 삭제

친구 API

친구 요청, 운동 상태 조회, 깨우기 알림, 친구 프로필과 루틴 조회 기능을 정리함

깨우기 알림

알림 관리 테이블 단순화

  • 기존에 깨우기 알림 관리를 하던 두 테이블 중 notification_cooldowns 삭제
  • 깨우기 알림만 관리하는 테이블명을 notification_events → notification_wakeup
  • last_sent_at을 notification_wakeup에서 관리
  • 같은 sender / receiver 기준으로 10분 쿨다운 확인
친구 요청
  • 수락,거절 해결된 알림은 삭제라 status삭제
  • 상대방이 수락하거나 거절한 시간도 필요 없어서 responded_at삭제
/친구 1. 친구요청 - POST /friend-requests 2. 친구요청 조회 - GET /friend-requests 3. 친구요청 수락/거절 - DELETE /friend-requests - 수락시 POST /friendship 4. 친구 삭제 - DELETE /friendships 5. 친구 운동 상태 조회 - GET /friends/workout-status - friendships에서 친구 아이디 조회 - 친구 user_id로 users에서 프로필, 칭호, 테마 조회 - 친구 user_id로 workouts에서 status 조회 - status가 운동중이면 운동중으로 판단 - status가 운동 완료이면 ended_at이 오늘 날짜이면 운동완료 - 오늘 날짜가 없으면 운동하지 않음 - workouts에 user_id 행이 없으면 운동하지 않음 6. 운동 상태마다 친구 인원 수 보여줌 - 친구 운동상태 조회 API에서 운동 상태별 수를 앱 내에서 카운트 7. 깨우기 알림 보내기 - POST /friends/wake-up - 친구 관계 확인 - 상대방 깨우기 알림 허용 여부 확인 - last_sent_at에서 10분 쿨다운 확인 - device_tokens에서 수신자 기기 토큰 조회 - FCM 알림 전송 - notification_wakeup 기록 - 쿨다운 시간 갱신 8. 친구 프로필 자세히 보기 - GET /friends/profile 9. 친구 루틴 보기 - GET /friends/routines

운동 / 헬스 API

운동 복구와 삭제, 헬스 운동 구성부터 시작·기록·완료·통계까지 정리함

운동 시간

일시정지 시간을 제외한 순 운동시간 계산

  • 일시정지 시 paused_at 저장
  • 재개 시 paused_seconds 누적
  • 일시정지 상태에서 완료 시 마지막 정지시간도 누적
duration_seconds = ended_at - started_at - paused_seconds
운동 공통
/운동 1. 운동 복구 - GET /workouts/active 2. 운동 기록 삭제 - DELETE /workouts
헬스
/운동 /헬스 0. 운동 짜기 - 루틴 가져오기 GET /routines - routine_days / routine_exercises / routine_sets - 내 루틴 목록 조회 - slot_no 선택 - routine_day 선택 - routine_exercises / routine_sets 조회 - 가져온 데이터들 앱 화면에 임시로 표시 - 수정시 exercises에서 목록 조회 - 직접 정하기 GET /body-parts / GET /exercises - 부위 선택 body_parts 조회 - 종목 선택 시 선택한 부위에 따라 exercises 목록 조회 - 선택한 부위가 없으면 전체 종목 조회 - 작성한 데이터들은 앱 내에서만 임시 표시 1. 운동 시작 - POST /workouts/strength - 시작 버튼 누를 때 앱 화면에 종목과 세트 데이터가 존재하면 strength_exercises와 strength_sets도 생성 - 없으면 workouts만 생성 - 루틴으로 운동 시작 시 해당 routines의 last_used_at을 현재시각으로 수정 2. 운동 중 - POST /strength-exercises - 운동 종목 선택 시 선택한 부위에 해당하는 종목만 목록 조회 - 시작 전 부위 선택하지 않았으면 종목 전체 목록 조회 - 한 종목에서 첫 세트 완료버튼 누를 시 strength_sets 생성 - PATCH /strength-sets - 한 세트 완료 표시를 누를 때마다 완료한 세트 수정 - 새로 추가한 세트는 POST - 일시정지 PATCH /workouts/pause - paused_at = 현재시각 - status = PAUSE - 재개 PATCH /workouts/resume - paused_seconds += (현재시각 - paused_at) - paused_at = NULL - status = IN_PROGRESS 3. 운동 완료 - PATCH /workouts/complete - 완료시각과 상태 수정 - 일시정지 상태에서 완료하면 마지막 정지시간을 paused_seconds에 누적 - duration_seconds = ended_at - started_at - paused_seconds 4. 운동 기록에 사진 촬영 - POST /workout-photos 5. 마이화면에서 운동요약 - GET /workouts/strength - workouts의 ended_at 날짜 기준으로 주 / 달 / 전체 정리 - strength_exercises, strength_sets에서 운동 종목, 세트, 횟수, 무게 정리 6. 마이화면에서 운동 캘린더 - GET /workouts/strength/calendar - 날짜별 운동 데이터 조회 7. 헬스 통계 - GET /workouts/strength/stats - 월별 총 볼륨 - 날짜별로 달을 나눔 - 달별로 strength_sets의 weight_kg × reps 합산 - 이번달 부위별 총 볼륨 - 이번달 운동기록만 가져옴 - strength_exercises의 exercise_id로 exercise의 부위를 찾음 - 같은 부위별로 나눔 - weight_kg × reps 합산

운동 / 러닝 API

러닝 시작, GPS 위치 기록, 일시정지·재개, 완료 기록과 러닝 코스 조회를 정리함

러닝 거리

실시간 계산과 서버 기록 역할 분리

  • GPS 위치는 앱에서 수집
  • 앱에서 이전 좌표와 현재 좌표 사이 거리 계산
  • 계산한 거리를 누적해 실시간 거리 표시
  • 좌표와 최종 거리 기록은 서버에 저장
  • 완료 후 코스와 기록은 저장된 데이터 조회
/운동 /러닝 1. 러닝 시작 - POST /workouts/running - workouts 생성 - running_details 생성 - 시작 전 입력한 목표거리 km → m 변환 - target_distance_m 저장 2. 러닝 중 - POST /running-route-points - 러닝 중 GPS 좌표 기록 - 유효한 위치가 들어올 때마다 좌표 저장 - 앱에서 이전 좌표와 현재 좌표 사이 거리 계산 - 계산한 거리를 누적해서 실시간 거리 표시 - 일시정지 / 재개 PATCH /workouts/status 일시정지 - status = PAUSED - paused_at = 현재시각 - 앱 위치 추적 중지 재개 - paused_seconds += (현재시각 - paused_at) - paused_at = NULL - status = IN_PROGRESS - 앱 위치 추적 재개 - 첫 포인트부터 segment_no + 1 3. 운동 완료 - PATCH /workouts/complete - 완료시각과 상태 수정 - 일시정지 상태에서 완료하면 마지막 정지시간을 paused_seconds에 누적 - duration_seconds = ended_at - started_at - paused_seconds - running_details 수정 - distance_m 최종 운동 거리 저장 4. 러닝 기록보기 - GET /workouts/running - 러닝 코스보기 GET /running-route-points - 해당 러닝의 GPS 포인트 조회 - 같은 segment_no끼리 묶음 - point_order 순서대로 정렬 - segment_no 묶음 안에서 순서대로 선 연결 5. 러닝 통계 - GET /workouts/running/stats - workouts의 기록 날짜 기준으로 주 / 달에 따라 workout_id 구분 - workout_id로 running_details 거리 조회 - 필요한 평균페이스, 칼로리는 앱 내에서 계산

친구 운동 비교와 루틴 생성·조회·수정·삭제·복사 기능을 정리함

랭킹
/랭킹 친구 운동순위 - GET /friends/workout-stats - 이번주 / 이번달 기준 - 친구 목록 조회 - 해당 기간의 친구 운동기록 비교 - 친구별 운동 날짜 수 비교 - 총 운동시간 비교 - 헬스 / 러닝 기록 구분해서 비교
루틴
루틴 데이터

루틴 원본과 실제 운동 기록 분리

  • 루틴 선택 시 DB에서 조회만 수행
  • 가져온 데이터는 앱 화면에 임시로 표시
  • 시작 전 종목·세트 수정 가능
  • 운동 시작 시 최종 화면 데이터를 strength_exercises / strength_sets로 생성
/루틴 1. 생성 - POST /routines - 앱에서 입력한 데이터 전송 - routines / routine_days / routine_exercises / routine_sets 생성 2. 조회 - GET /routines - routines / routine_days / routine_exercises / routine_sets 조회 3. 수정 - PUT /routines - 화면에서 수정된 최종 루틴 데이터 전체 전송 - routines / routine_days / routine_exercises / routine_sets 전체 반영 4. 삭제 - DELETE /routines - routines / routine_days / routine_exercises / routine_sets 전체 삭제 5. 복사 - POST /friends/{friendId}/routines/{routineId}/copy - 친구의 해당 루틴 전체 조회 - 내 저장할 slot_no 선택 - 기존 루틴이 있으면 교체 - 없으면 새로 생성 - routines / routine_days / routine_exercises / routine_sets 전체 반영
