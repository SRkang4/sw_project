S/W 프로그래밍 · 폴더 구조와 화면별 기능 흐름

1. 파일 구조 2. 앱 실행과 화면별 기능

1. 파일 구조

lib/ 아래의 주요 폴더를 역할별로 정리했습니다. 다음 챕터에서도 같은 폴더에는 같은 색상을 사용합니다.

screens/ 화면 홈, 운동, 친구, 랭킹, 로그인 등 사용자가 보는 화면 구성
services/ 기능·데이터 처리 Firebase 연결, 로그인, 데이터 조회·저장, 알림 등의 실제 기능 처리
models/ 데이터 형태 친구, 운동 기록, 랭킹 등 앱에서 사용하는 데이터의 구조 정의
widgets/ 재사용 화면 요소 여러 화면에서 사용하는 버튼, 카드, 타이머 등의 UI 구성
controllers/ 상태 관리 운동 시간과 진행 상태처럼 계속 바뀌는 앱 상태 관리
navigation/ 화면 이동 탭 이동 요청 등 화면 간 이동 제어
theme/ 화면 스타일 밝기 모드, 강조 색상, 프로필 카드 등 테마 설정
data/ 기본 데이터 헬스 종목 목록처럼 앱에서 사용하는 미리 정해진 데이터
utils/ 공통 보조 기능 공동 순위 계산처럼 여러 곳에서 활용할 수 있는 계산·도우미 기능
config/ 앱 설정 앱 동작에 사용하는 설정값 관리
폴더 밖의 주요 파일

main.dart → 앱 시작과 초기화

app.dart → 앱 전체 구성과 로그인 상태에 따른 화면 연결

firebase_options.dart → Firebase 연결 설정

2. 앱 실행과 화면별 기능

각 파일이 맡는 기능과 연결되는 서비스·모델·화면 요소를 정리했습니다.

main.dart app.dart screens/main_screen.dart screens/home_screen.dart screens/workout_screen.dart screens/friends_screen.dart screens/ranking_screen.dart screens/my_page_screen.dart screens/settings_screen.dart screens/login_screen.dart screens/email_login_screen.dart screens/signup_screen.dart

main.dart

  • Firebase / 테마 초기화
    firebase_options.dart의 Firebase 연결 설정 사용, theme/theme_controller.dart에서 저장된 테마 불러오기
  • 앱 실행
    app.dart의 ShareFitApp 실행
  • 푸시 알림 초기화
    services/push_notification_service.dart에서 알림 수신 설정, services/fcm_token_service.dart에서 기기 알림 토큰 등록

app.dart

  • 테마 상태 반영
    theme/theme_controller.dart의 변경을 감지하고 theme/app_theme.dart의 테마 적용
  • 로그인 인증 상태 확인
    자체 처리: Firebase Auth의 로그인 상태 변화 감지
  • 로그인 상태
    MainScreen → services/auth_service.dart에서 사용자 프로필 생성·보완, screens/main_screen.dart 표시
  • 비로그인 상태
    LoginScreen → screens/login_screen.dart 표시
  • 운동 중 전역 타이머 배치
    widgets/active_workout_timer_pill.dart로 표시, controllers/workout_session_controller.dart에서 운동 시간·상태 관리

screens/main_screen.dart

  • 하단 네비게이션 바 관리
    자체 처리: 선택 탭 관리, navigation/app_navigation_controller.dart의 탭 이동 요청 반영
  • 선택된 탭에 해당하는 화면 표시
    screens/의 home_screen.dart, workout_screen.dart, friends_screen.dart, ranking_screen.dart, my_page_screen.dart를 IndexedStack으로 전환

screens/home_screen.dart

  • 친구 목록 표시
    services/friend_service.dart에서 친구 목록 실시간 정보 받아오기, models/friend.dart의 친구 정보 사용
  • 친구별 운동 상태 표시
    services/public_activity_service.dart에서 공개 운동 상태 실시간 정보 받아오기, models/public_activity.dart로 상태 해석
  • 친구의 오늘 운동 기록 표시
    services/public_workout_activity_service.dart에서 오늘 공개 기록 조회, models/public_workout_activity.dart의 기록 사용
  • 깨우기 알림 요청
    services/wake_up_service.dart에서 서버의 sendWakeUp 함수 호출

screens/workout_screen.dart

  • 헬스/러닝 준비 화면
    자체 처리: 운동 종류·목표 설정, widgets/exercise_picker_sheet.dart와 data/exercise_catalog.dart로 헬스 종목 선택
  • 운동 시작 후 진행 화면 표시
    controllers/workout_session_controller.dart에서 시간·진행 상태 관리, services/location_tracking_service.dart로 러닝 위치 추적, services/public_activity_service.dart로 운동 시작 상태 공개
  • 운동 완료 후 기록 정리 및 표시
    models/workout_record.dart로 기록 구성, services/workout_service.dart에서 저장·조회, widgets/workout_record_detail.dart로 기록 상세 표시
  • 운동 기록 삭제
    services/workout_service.dart에서 기록 삭제·통계 조정, services/workout_photo_service.dart에서 연결된 인증 사진 삭제
  • 인증 사진 등록
    자체 처리: image_picker로 사진 촬영, services/workout_photo_service.dart에서 업로드, services/workout_service.dart에서 기록에 사진 정보 연결

screens/friends_screen.dart

  • 친구 검색/요청/수락/거절/취소/삭제 UI
    services/friend_service.dart에서 친구 코드 검색과 관계 변경 처리, models/friend.dart와 models/friend_request.dart로 친구·요청 정보 관리
  • 기존 사용자 친구 관련 데이터 보완 요청
    services/friend_service.dart의 migrateCurrentUser()에서 친구 코드·공개 프로필·친구 수 데이터 보완

screens/ranking_screen.dart

  • 항목별 랭킹 데이터 정렬
    services/ranking_service.dart에서 기간별 데이터 조회, models/ranking_entry.dart의 값을 화면 내부에서 항목별 정렬
  • 순위 및 공동 순위 계산/표시
    utils/competition_ranking.dart에서 공동 순위 계산, 화면 내부에서 순위 표시

screens/my_page_screen.dart

  • 프로필 커스터마이징
    services/auth_service.dart에서 이름 등 프로필 수정, services/profile_customization_service.dart에서 꾸미기 설정 저장, theme/profile_card_theme.dart로 카드 테마 적용
  • 운동 요약
    services/workout_service.dart에서 완료 기록 조회, 화면 내부에서 주·월·전체 운동량 합산
  • 날짜별 운동 기록
    services/workout_service.dart의 watchWorkoutsForDate()로 조회, widgets/workout_history_card.dart로 표시
  • 운동 상세 통계
    services/advanced_stats_service.dart에서 최근 6개월 통계 계산, models/advanced_stats.dart의 통계 데이터 사용
  • 설정 화면 진입
    screens/settings_screen.dart로 이동

screens/settings_screen.dart

  • 테마 설정
    theme/theme_controller.dart에서 밝기 모드·강조 색상 변경 및 저장, theme/app_theme_color.dart의 색상 목록 사용
  • 알림 설정
    services/notification_preferences_service.dart에서 알림 수신 설정 불러오기·저장
  • 로그아웃
    services/auth_service.dart의 signOut() 호출
  • 계정 삭제
    services/auth_service.dart의 deleteAccount() 호출
  • 이용약관
    현재 자체 메뉴 UI만 표시하며, 약관 화면이나 실행 동작은 연결되지 않음

screens/login_screen.dart

  • Google 로그인
    services/auth_service.dart에서 Firebase 로그인·프로필 준비, services/google_auth_client.dart에서 Google 계정 인증, widgets/google_sign_in_button.dart로 버튼 표시
  • 이메일 로그인 화면 진입
    screens/email_login_screen.dart로 이동

screens/email_login_screen.dart

  • 이메일/비밀번호 검증
    자체 처리: 이메일 형식과 이메일·비밀번호 입력 여부 검사
  • 이메일 로그인
    services/auth_service.dart의 signIn()으로 Firebase 이메일 로그인
  • 회원가입 화면 진입
    screens/signup_screen.dart로 이동
  • 비밀번호 찾기 인증 메일 발송
    현재 버튼만 있고 클릭 동작이 비어 있어 메일 발송 미구현

screens/signup_screen.dart

  • 이메일/비밀번호/이름 검증
    자체 처리: 이메일 형식·비밀번호 조건·비밀번호 확인·이름 입력 검사
  • 계정 생성
    services/auth_service.dart의 signUp()으로 Firebase 계정 및 사용자·친구 코드·공개 프로필 데이터 생성
